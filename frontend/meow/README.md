# Мяу-пианино

Публичная музыкальная игрушка FraerApp: `/meow/`, ссылка на главной рядом с
«Все истории». Стек существующего frontend сохранён: HTML, CSS, JavaScript ES
modules. React/Vite и сервер приложению не нужны; авторизация отсутствует.

## Запуск и сборка

Из корня репозитория, Node.js 20+ и Python 3:

```sh
npm install
npm run dev:meow
# Открыть http://127.0.0.1:8766/meow/
npm run build
# Или только игрушка:
npm run build:meow
```

Зависимостей приложения нет. `npm install` не обязателен. Общая сборка запускает
проверки production-конфигурации существующего сайта, проверяет синтаксис модулей
игрушки и собирает самодостаточную папку `dist/meow/` из 10 статических файлов.
Для работы страницы нужен HTTP(S), открытие HTML через `file://` не поддерживается.

Для отдельного статического хостинга загрузите содержимое `dist/meow/` в корень
сайта или папку `/meow/`. Включите обычную раздачу `index.html`, корректные MIME
типы `.js`, `.css`, `.svg` и HTTPS. SPA rewrite не требуется. Ссылка FraerApp
ведёт на `/`; при отдельном размещении её можно заменить на адрес основного сайта.
На FraerApp nginx уже раздаёт `frontend/` и индексные файлы каталогов.

## Устройство

- `config.js`: 13 нот C4–C5, KeyboardEvent.code, котики, индивидуальные тембры.
- `input.js`: владение нотами по источникам, Pointer Events и физическая клавиатура.
- `audio.js`: полифонический Web Audio синтез, огибающие, форманты, компрессор.
- `cats.js`, `scene.js`: оригинальные SVG, расположение хора и анимация голосов.
- `piano.js`: клавиши и доступные подписи; `app.js`: связывает компоненты и состояния.

A W S E D F T G Y H U J K соответствуют хроматическим нотам от C4 до C5.
Удержание поддерживается мышью, физической клавиатурой и несколькими пальцами.
Tab выбирает клавишу, Space/Enter играет выбранную ноту. При удержании одной ноты
несколькими источниками она отпускается только после освобождения всех источников.
Потеря фокуса, скрытие страницы, pagehide, pointercancel, lostpointercapture и
прерывание аудиоконтекста сбрасывают соответствующие нажатия.

Кнопка «Тембр» рядом с громкостью открывает ползунок «Носовой ↔ Открытый».
Сдвиг вправо уменьшает носовой призвук и поднимает вокальные резонансы; влево
делает голос более закрытым. Настройку можно менять во время удержания ноты:
переход сглаживается за 25 мс и не меняет частоту музыкального генератора.
Значение сохраняется локально в браузере; «Сбросить» возвращает 50%.
Панель не закрывает клавиши; Escape закрывает её и возвращает фокус на кнопку.

## Звук, ресурсы и права

**Используется синтезированный звук**, не запись настоящего кота. Никакие сторонние
сэмплы не загружаются. Гармонический источник проходит три параллельных формантных
фильтра: отдельное приглушённое носовое «м» переходит в «и-я-а», при отпускании —
в «у». Гласные плавно подключаются за 25–85 мс, без резкого широкополосного
начала. Переход в «у» занимает первые 55 мс отпускания, пока голос ещё слышен.
У каждого кота свои резонансы и вибрато. Это выразительный стилизованный голос, не реалистичная
запись животного. Начальная интонация поднимается от −140 до +35 центов за 90 мс
и приходит к целевой ноте за 180 мс; затем высота соответствует равномерной
темперации A4=440 Hz с вибрато ±7 центов.

Минимальная нота — 160 мс, мягкое отпускание — 180 мс. Короткий тап остаётся
слышимым и видимым. Удержание не ограничено по времени. Все 13 нот могут звучать
вместе; общий компрессор ограничивает громкость аккордов. Хвосты быстрых повторов
ограничены 32 голосами. После подготовки аудио игра не делает сетевых запросов.
AudioContext создаётся/возобновляется непосредственно из действия пользователя;
ошибки и кнопка повторного включения отображаются под инструментом.

Все 13 SVG-котиков и favicon нарисованы для этого проекта, все элементы и код
синтеза находятся в исходниках. Сторонних изображений, звуков, шрифтов, платных
сервисов или внешних API нет. Используются системные шрифты. Код и оригинальные
ресурсы следуют условиям основного репозитория; сторонние аудиолицензии отсутствуют.

## Проверки

Выполнено 23 октября 2026: production-сборка, 55 базовых Node-тестов (включая
2 теста владения нотами), Chromium-сценарии ниже, гостевая главная на четырёх
ширинах и `git diff --check`. На реальном сайте сверены SHA-256 всех 12
публикуемых ресурсов, шесть сервисов, health/API и свежие логи.

```sh
node --test frontend/meow/input.test.js
# Для браузерных проверок нужен Playwright с Chromium:
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:meow
# Для проверки опубликованной версии:
MEOW_BASE_URL=https://example.com node scripts/check-meow.cjs
```

В среде Codex вместо установки можно предоставить Playwright через `NODE_PATH`.
`scripts/check-meow.cjs` поднимает локальный сервер и проверяет короткий тап,
удержание, keydown.repeat, русскую раскладку, совместное управление одной нотой,
быстрый повтор, 13 нот, mute, blur, visibilitychange, отмену мультитача, потерю
pointer capture, прерывание AudioContext, отсутствие сетевых запросов при игре,
шесть размеров экрана, reduced motion и сообщение об отсутствии Web Audio.
OfflineAudioContext измеряет высоту всех нот, продолжение удержания, слышимость
короткой ноты, нулевой хвост после отпускания, mute и пик аккорда.
Дополнительно сравнивается спектральная яркость начала, открытой гласной и конца:
начало должно быть приглушённым, а конец — округляться до исчезновения звука.
Это проверяет артикуляцию синтезатора, но не доказывает узнаваемость мяуканья.

Ограничения: автоматические проверки Chromium не заменяют прослушивание человеком
и испытания на физических iOS/Android устройствах. Скрытие страницы моделируется
событием visibilitychange. В коротком горизонтальном окне доступна вертикальная
прокрутка; на узком телефоне чёрные клавиши меньше рекомендуемой сенсорной ширины
44px, поэтому для сложных аккордов удобнее повернуть телефон. Аппаратная задержка
зависит от браузера, устройства и Bluetooth. Звук начинается после первого
действия пользователя, как требует браузерная политика.
